# Claude поверх экрана

Экранный помощник, который работает по **подписке Claude (Pro/Max)**, без API-ключа.
Запросы идут через официальный Claude Code: он входит в твой аккаунт так же, как
claude.ai, и расходует лимиты подписки.

Приложение состоит из **двух отдельных программ**:

| Программа | Запуск | Что делает |
|---|---|---|
| **Управление** | `start_manager.bat` | Чаты и выбор, с каким работает оверлей; загрузка контекста (переписка, файлы); настройки; запуск и остановка оверлея |
| **Оверлей** | `start_overlay.bat` | Работает в фоне без окон: горячие клавиши → скриншот → ответ в полупрозрачной панели поверх экрана. Панель пропускает клики мыши |

Программы работают с общими данными: оверлей отвечает в чате, выбранном в
«Управлении», а его ответы сразу появляются в переписке этого чата. Оверлей можно
запускать и без открытого «Управления».

## Установка (Windows)

1. Поставь **Python 3.10+** с python.org. При установке отметь «Add Python to PATH».
2. Запусти `install.bat` (поставит `mss` и `Pillow`).
3. Открой `start_manager.bat`. Если Claude Code ещё не установлен или ты не вошёл в
   аккаунт, сразу откроется **⚙ Настройки → Аккаунт**:
   - **«Установить Claude Code»** — установка в отдельном окне (пара минут);
   - **«Войти в аккаунт Claude»** — откроется браузер с claude.ai. Войди и подтверди
     доступ. Если браузер покажет код, вставь его в появившееся окно терминала и
     нажми Enter. Статус обновится сам.

## Как пользоваться

1. **В «Управлении»** создай чат («+ Новый чат») или выбери существующий. Оверлей
   работает с тем чатом, который выбран в списке.
2. **Загрузи контекст**: напиши, что будешь присылать и как отвечать, прикрепи файлы
   (📎: PDF, картинки, txt/md/код, .docx). В поле **«Что делать со скриншотами»**
   можно задать инструкцию, которая уходит с каждым скриншотом в этом чате.
3. **Запусти оверлей**: кнопкой «▶ Запустить» вверху «Управления» или через
   `start_overlay.bat`. «Управление» после этого можно закрыть.
4. Жми горячие клавиши:

| Клавиши | Что делает |
|---|---|
| `Ctrl+Alt+S` | скриншот всего экрана → Claude |
| `Ctrl+Alt+A` | выделить область мышью → Claude (Esc — отмена) |
| `Ctrl+Alt+H` | скрыть / показать панель |
| `Ctrl+Alt+PgUp` / `PgDn` | прокрутить длинный ответ |
| `Ctrl+Alt+M` | режим перемещения: перетащи панель мышью, повторное нажатие закрепит |
| `Ctrl+Alt+C` | открыть «Управление» |
| `Ctrl+Alt+X` | остановить ответ |
| `Ctrl+Alt+Q` | закрыть оверлей |

Клавиши работают в любой раскладке. Поменять их можно в **⚙ Настройки → Горячие
клавиши**: «Изменить» → нажать новое сочетание. Кнопка ✕ отключает сочетание.
Пока открыто окно настроек, клавиши оверлея на паузе.

У каждого чата свой диалог с Claude: договорённости и файлы из одного чата не
смешиваются с другим. После перезапуска чаты продолжаются с того же места.

## Настройки (⚙ в «Управлении»)

- **Аккаунт** — установка Claude Code, вход и выход, текущий статус.
- **Горячие клавиши** — назначить, отключить, вернуть по умолчанию.
- **Вид панели** — тема (тёмная, светлая или как в системе), ширина, высота,
  шрифт, прозрачность, автоскрытие.
- **Положение → «Как показывать ответ»**:
  - *Текстом в панели* — ответ в полупрозрачной панели (как раньше);
  - *Пометками по всему экрану* — Claude обводит нужные места рамками с номерами и
    пишет короткие подписи рядом: ответ у каждого вопроса, «нажми сюда» у кнопки,
    «ошибка тут» у строки. Точность — до нескольких десятков пикселей, лучше всего
    со скриншотом области (`Ctrl+Alt+A`). `Ctrl+Alt+H` скрывает и показывает пометки,
    новый скриншот заменяет их. Можно задать, через сколько секунд они исчезают.
    Ответ текстом сохраняется в чат, а если пометки не получились, он показывается
    в панели.
- **Положение** — монитор (тот, где курсор; основной; конкретный), место на экране
  (9 точек: углы, середины сторон, центр), отступы по горизонтали и вертикали,
  «не заходить на панель задач». Если панель перетащили мышью (`Ctrl+Alt+M`),
  «Вернуть к привязке» снова ставит её в выбранное место.
- Изменения вида и положения сразу показываются в панели предпросмотра.
- **Claude** — модель (`sonnet` быстрее, `opus` умнее), размер скриншота, текст к
  скриншоту по умолчанию, путь к Claude Code, кнопка для `CLAUDE.md`.

Запущенный оверлей подхватывает изменения сам, перезапускать его не нужно.
Всё хранится в `config.json`; чаты — в `data/chats/`.

`workspace/CLAUDE.md` — постоянные инструкции для Claude во всех чатах: язык,
стиль, краткость. Изменения действуют с новых чатов. Прикреплённые файлы копируются
в `workspace/files/`.

## Безопасность

Claude здесь может **только читать файлы** в папке `workspace`. Запуск команд,
изменение файлов и интернет отключены (`--tools Read`).

## Если что-то не так

- «Не выполнен вход»: «Управление» → ⚙ Настройки → Аккаунт → «Войти в аккаунт Claude».
- «Не найден Claude Code»: ⚙ Настройки → Аккаунт → «Установить», или укажи путь на
  вкладке Claude. Обычно это `C:\Users\<имя>\.local\bin\claude.exe`.
- Горячая клавиша «занята другой программой»: назначь другую в ⚙ Настройки.
- «Чат сейчас занят»: в этом чате уже отвечает Claude (из «Управления» или оверлея),
  дождись ответа.
- Ответ долгий: первый запрос в чате всегда медленнее. Для скорости выбери `sonnet`.
- Лимиты общие с claude.ai: каждый скриншот расходует сообщение из подписки.

macOS и Linux тоже поддерживаются (`pip install -r requirements.txt`, затем
`python3 manager.py` и `python3 overlay.py`), но там панель не пропускает клики,
а на macOS для горячих клавиш нужно разрешение «Универсальный доступ».

## Обновление со старой версии

Единственный диалог из первой версии (`state.json`) при первом запуске
автоматически переносится в чат «Чат 1».
