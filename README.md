# Claude поверх экрана

Экранный помощник, который работает по **подписке Claude (Pro/Max)**, без API-ключа.
Запросы идут через установленный Claude Code (`claude`): он входит в твой аккаунт
так же, как claude.ai, и тратит лимиты подписки.

- **Окно чата.** Здесь заранее обсуждаешь, что делать со скриншотами, и прикрепляешь
  файлы (PDF, картинки, txt/md/код, .docx).
- **Горячая клавиша.** Скриншот экрана или выделенной области уходит в тот же диалог,
  а ответ появляется в полупрозрачной панели в углу. Панель всегда сверху и **пропускает
  клики мыши**, то есть не мешает работать.

## Установка (Windows)

1. Поставь **Python 3.10+** с python.org. При установке отметь «Add Python to PATH».
2. Поставь **Claude Code**. В PowerShell:
   ```
   irm https://claude.ai/install.ps1 | iex
   ```
3. Открой новое окно терминала, выполни `claude` и войди аккаунтом с подпиской.
   Нужен один раз, потом окно можно закрыть.
4. Запусти `install.bat` (поставит `mss` и `Pillow`).
5. Запускай `start.bat`.

> Если в системе задана переменная `ANTHROPIC_API_KEY`, приложение её игнорирует,
> чтобы запросы точно шли по подписке.

## Как пользоваться

1. В окне чата напиши, что будешь присылать и как отвечать. Например: «Буду кидать
   задачи по физике, давай ответ и короткое решение». Прикрепи методичку, если нужно.
2. Сверни окно.
3. Жми горячие клавиши:

| Клавиши | Что делает |
|---|---|
| `Ctrl+Alt+S` | скриншот всего экрана → Claude |
| `Ctrl+Alt+A` | выделить область мышью → Claude (Esc — отмена) |
| `Ctrl+Alt+H` | скрыть / показать панель |
| `Ctrl+Alt+PgUp` / `PgDn` | прокрутить длинный ответ |
| `Ctrl+Alt+M` | режим перемещения: перетащи панель мышью, повторное нажатие закрепит |
| `Ctrl+Alt+C` | открыть окно чата |
| `Ctrl+Alt+X` | остановить ответ |

Клавиши работают в любой раскладке. Поменять их можно в `config.json`.

Все скриншоты и сообщения из чата попадают в **один диалог**, поэтому Claude помнит
договорённости и файлы. «Новый диалог» начинает с чистого листа. После перезапуска
программы диалог продолжается.

## Настройки — `config.json` (создаётся при первом запуске)

- `model` — `""` (по умолчанию), `sonnet` (быстрее), `opus`, `haiku`, `fable`.
  Модель также можно выбрать в окне чата.
- `screenshot_prompt` — текст, который уходит вместе со скриншотом по горячей клавише.
- `overlay.width`, `max_height`, `opacity`, `font_size`, `corner`
  (`top-right` / `top-left` / `bottom-right` / `bottom-left`), `auto_hide_seconds`.
- `hotkeys` — сочетания вида `ctrl+alt+s`, `ctrl+shift+f9`, `alt+pagedown`.
- `claude_path` — путь к `claude.exe`, если программа не нашла его сама.

`workspace/CLAUDE.md` — постоянные инструкции для Claude: язык, стиль, краткость.
Их можно править, изменения действуют с нового диалога. Прикреплённые файлы
копируются в `workspace/files/`.

## Безопасность

Claude здесь может **только читать файлы** в папке `workspace`. Запуск команд,
изменение файлов и интернет отключены (`--tools Read`).

## Если что-то не так

- «Claude Code не авторизован»: запусти `claude` в терминале и войди.
- «Не найден Claude Code»: укажи путь в `claude_path`. Обычно это
  `C:\Users\<имя>\.local\bin\claude.exe`.
- Горячая клавиша «занята другой программой»: поменяй её в `config.json`.
- Ответ долгий: первый запрос в диалоге всегда медленнее. Для скорости выбери `sonnet`.
- Лимиты общие с claude.ai: каждый скриншот расходует сообщение из подписки.

macOS и Linux тоже поддерживаются (`pip install -r requirements.txt`, `python3 app.py`),
но там панель не пропускает клики, а на macOS программе нужно разрешение
«Универсальный доступ» для горячих клавиш.
