# ИИ-помощник поверх экрана

Программа, которая по нажатию клавиш **делает снимок экрана, отправляет его нейросети
и показывает ответ в небольшой полупрозрачной панели поверх всех окон**. Панель не
мешает работать: сквозь неё можно кликать мышью, её можно скрыть одним сочетанием
клавиш.

Пример: у тебя открыта задача, таблица или ошибка в программе. Нажимаешь
`Ctrl+Alt+S` — через несколько секунд в углу экрана появляется объяснение или решение.

Работает с **Claude, ChatGPT, Gemini, Grok, GigaChat, OpenRouter и Ollama**. Claude и
ChatGPT можно подключить **по обычной подписке** (без оплаты за API), а Gemini,
GigaChat, OpenRouter и Ollama — **бесплатно**.

## Из чего состоит программа

Это **две отдельные программы**, которые работают вместе:

| Программа | Как выглядит | Зачем нужна |
|---|---|---|
| **Управление** | Обычное окно со списком чатов | Создать чат, заранее объяснить нейросети задачу, прикрепить файлы, выбрать нейросеть, поменять настройки, запустить оверлей |
| **Оверлей** | Окна нет — работает в фоне. Видна только панель с ответом | Ждёт горячих клавиш, делает снимок экрана и показывает ответ |

Оверлей отвечает в том чате, который выбран в «Управлении», и его ответы сразу
появляются в переписке этого чата. После запуска оверлея окно «Управления» можно
закрыть — оверлей продолжит работать.

> **Словарик.** *Оверлей* — то, что рисуется поверх других окон. *Горячие клавиши* —
> сочетание вроде `Ctrl+Alt+S`: зажимаешь `Ctrl` и `Alt` и нажимаешь `S`.
> *Контекст* — то, что нейросеть знает о задаче заранее: твои пояснения и файлы.

## Установка

Понадобится **Python 3.10 или новее** — это бесплатная среда, на которой написана
программа. Всё остальное установщик поставит сам.

### Шаг 0. Скачай программу

1. Открой страницу репозитория на GitHub.
2. Нажми зелёную кнопку **Code** → **Download ZIP**.
3. Распакуй архив в удобное место, например в `Документы`. Не клади программу в
   `Program Files` — там ей не хватит прав сохранять настройки.

Внутри будут папки:

```
windows/   — файлы для Windows
linux/     — файлы для Linux
macos/     — файлы для macOS
src/       — код программы (трогать не нужно)
```

В папке своей системы три файла:

- `install` — **установка** (запустить один раз);
- `start_manager` — **открыть «Управление»**;
- `start_overlay` — **запустить оверлей** (можно и кнопкой из «Управления»).

### Windows

1. **Установи Python.** Зайди на [python.org/downloads](https://www.python.org/downloads/),
   нажми жёлтую кнопку *Download Python* и запусти скачанный файл.
   **Важно:** на первом экране установщика поставь галочку
   **«Add python.exe to PATH»**, потом нажми *Install Now*.
2. **Запусти установку программы.** Открой папку `windows` и дважды щёлкни
   `install.bat`. Появится чёрное окно — это нормально. Подожди, пока не появится
   надпись «Готово», и нажми любую клавишу.
   - Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
     нажми **«Подробнее» → «Выполнить в любом случае»**.
3. **Открой программу:** дважды щёлкни `windows\start_manager.bat`.

Чтобы не искать файл каждый раз, сделай ярлык: правый щелчок по
`start_manager.bat` → **«Отправить» → «Рабочий стол (создать ярлык)»**.

### Linux

1. **Установи Python и модули для окон.** Открой терминал и выполни
   (Ubuntu, Debian, Mint):
   ```bash
   sudo apt install python3 python3-venv python3-tk
   ```
   Fedora: `sudo dnf install python3 python3-tkinter`, Arch: `sudo pacman -S python tk`.
2. **Перейди в папку программы** (путь подставь свой):
   ```bash
   cd ~/Загрузки/Overlay-assistant-for-Claude-main
   ```
3. **Запусти установку:**
   ```bash
   bash linux/install.sh
   ```
4. **Открой программу:**
   ```bash
   bash linux/start_manager.sh
   ```

> **Важно для Linux.** Горячие клавиши и снимки экрана работают в сеансе **Xorg
> (X11)**. Во многих новых дистрибутивах по умолчанию включён Wayland — тогда на
> экране входа (где вводишь пароль) нажми на шестерёнку и выбери
> **«Ubuntu on Xorg»** или похожий пункт.

### macOS

1. **Установи Python** с [python.org/downloads](https://www.python.org/downloads/)
   (обычный установщик .pkg — в нём уже есть всё нужное).
2. **Запусти установку:** открой папку `macos` и дважды щёлкни `install.command`.
   - Если macOS пишет, что файл «от неустановленного разработчика», — щёлкни
     по нему **правой кнопкой → «Открыть» → «Открыть»**.
   - Если файл не открывается вовсе — открой «Терминал», перетащи в него файл
     `install.command`, допиши перед ним `bash ` и нажми Enter.
3. **Открой программу:** дважды щёлкни `macos/start_manager.command`.
4. **Дай разрешения.** При первом снимке экрана macOS спросит доступ. Открой
   **«Системные настройки» → «Конфиденциальность и безопасность»** и включи
   «Терминал» (или «Python») в двух разделах:
   - **Универсальный доступ** — чтобы работали горячие клавиши;
   - **Запись экрана** — чтобы делались снимки.

   После этого перезапусти оверлей.

## Первый запуск: подключаем нейросеть

При первом запуске «Управления» само откроется окно **⚙ Настройки → Нейросети**.
Вверху выбери нейросеть из списка — ниже появятся её настройки.

### Claude (по подписке Pro/Max)

1. Выбери **Claude**, способ доступа — **«Подписка Claude — вход в аккаунт»**.
2. Нажми **«Установить Claude Code»**. Откроется окно, в котором пройдёт установка;
   когда она закончится, окно можно закрыть.
3. Нажми **«Войти через браузер»** и подтверди вход на сайте Claude.
   Если браузер на другом устройстве — нажми **«Войти по ссылке»**: появится ссылка,
   её можно скопировать и открыть где угодно, а полученный код вставить обратно.
4. Нажми **«Проверить»** — должен прийти пробный ответ.

### ChatGPT (по подписке, в том числе бесплатной)

1. Выбери **ChatGPT**, способ доступа — **«Подписка ChatGPT — через Codex»**.
2. Нажми **«Установить Codex»** и дождись конца установки.
3. Нажми **«Войти через браузер»** (или **«Войти по коду»**, если браузер на другом
   устройстве) и войди в свой аккаунт ChatGPT.
4. Поле «Модель» можно оставить пустым — модель выберется сама.
5. Нажми **«Проверить»**.

### Нейросети по ключу (Gemini, GigaChat, OpenRouter, Grok и др.)

*Ключ* (API-ключ) — это длинный пароль, который выдаёт сайт нейросети. По нему
программа отправляет запросы от твоего имени.

1. Выбери нейросеть.
2. Нажми **«Получить»** рядом с полем ключа — откроется нужный сайт. Зарегистрируйся
   и создай ключ.
3. Скопируй ключ и вставь его в поле.
4. Нажми **«Список моделей»** и выбери модель, которая **понимает картинки**.
5. Нажми **«Проверить»**, затем **«Сохранить»**.

### Ollama (бесплатно и без интернета)

Нейросеть работает прямо на твоём компьютере. Нужна мощная видеокарта.
Нажми **«Скачать Ollama»**, установи её, затем скачай модель, которая понимает
картинки, и выбери её в настройках.

## Какую нейросеть выбрать

| Если у тебя… | Выбирай | Сколько стоит |
|---|---|---|
| Подписка Claude Pro или Max | **Claude** → «Подписка» | Входит в подписку |
| Аккаунт ChatGPT (даже бесплатный) | **ChatGPT** → «Подписка» | Входит в подписку / бесплатно с лимитами |
| Ничего нет, но есть VPN | **Gemini** | Есть бесплатный тариф |
| Ничего нет и нет VPN | **GigaChat** | Есть бесплатный режим |
| Хочется попробовать разные модели | **OpenRouter** | Есть бесплатные модели (`:free`, около 50 запросов в день) |
| Мощная видеокарта | **Ollama** | Бесплатно |
| Ключ API (оплата за каждый запрос) | Claude / ChatGPT → «API-ключ», **Grok** | По тарифам сервиса |

Полезно знать:

- **Из России** ChatGPT, Gemini, Grok и OpenRouter работают **только через VPN**.
  GigaChat работает без VPN.
- **GigaChat** иногда требует сертификат Минцифры («Russian Trusted Root CA», есть на
  Госуслугах). Его можно установить в систему или указать файлом в настройках
  GigaChat.
- **Лимиты подписки общие** с сайтом: каждый снимок экрана — это одно сообщение из
  твоей подписки.
- **В каждом чате можно выбрать свою нейросеть** — список «Нейросеть» вверху окна
  «Управление». Если сменить нейросеть посреди чата, новая получит прошлую переписку.
- Галочка **«по умолчанию для новых чатов»** в настройках задаёт нейросеть, которая
  будет у всех новых чатов.

## Как пользоваться

1. **Создай чат.** В «Управлении» нажми **«+ Новый чат»**. Оверлей всегда работает с
   чатом, который **выделен в списке слева**.
2. **Объясни задачу заранее (необязательно, но очень помогает).** Напиши в чат,
   что ты будешь присылать и как отвечать. Например: *«Буду присылать задачи по
   физике. Решай кратко, только формулы и ответ»*. Можно прикрепить файлы кнопкой
   **📎 Файлы**: PDF, картинки, текст, код, документы Word.
3. **Задай инструкцию для снимков (необязательно).** Поле **«Что делать со
   скриншотами»** — этот текст уходит вместе с каждым снимком в этом чате.
4. **Запусти оверлей** кнопкой **«▶ Запустить»** вверху «Управления». В углу экрана
   ненадолго появится панель «Оверлей запущен».
5. **Пользуйся:** нажми `Ctrl+Alt+S` — снимок всего экрана, или `Ctrl+Alt+A` —
   выдели мышью нужную часть экрана. Ответ появится в панели.

Чаты не смешиваются: договорённости и файлы одного чата не видны в другом. После
перезапуска компьютера всё сохраняется, разговор продолжается с того же места.

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| `Ctrl+Alt+S` | Снимок **всего экрана** → нейросети |
| `Ctrl+Alt+A` | Выделить **часть экрана** мышью → нейросети (`Esc` — отмена) |
| `Ctrl+Alt+H` | Скрыть / показать панель |
| `Ctrl+Alt+PgUp` / `Ctrl+Alt+PgDn` | Прокрутить длинный ответ вверх / вниз |
| `Ctrl+Alt+M` | Переместить панель: перетащи её мышью, нажми ещё раз — закрепится |
| `Ctrl+Alt+C` | Открыть «Управление» |
| `Ctrl+Alt+X` | Остановить ответ |
| `Ctrl+Alt+Q` | Закрыть оверлей |

Клавиши работают при любой раскладке (русской или английской). Поменять их:
**⚙ Настройки → Горячие клавиши → «Изменить»** и нажми новое сочетание. Кнопка **✕**
отключает сочетание. Пока открыто окно настроек, клавиши оверлея не срабатывают.

## Настройки

Кнопка **⚙ Настройки** в «Управлении». Изменения применяются после **«Сохранить»**,
запущенный оверлей подхватывает их сам.

| Вкладка | Что там |
|---|---|
| **Нейросети** | Выбор нейросети, способ доступа, вход или ключ, модель, **уровень усилий** (чем выше — тем дольше думает и точнее отвечает), кнопка «Проверить» |
| **Горячие клавиши** | Назначить, отключить, вернуть по умолчанию |
| **Вид панели** | Тема (тёмная, светлая, как в системе), размер, шрифт, прозрачность, автоскрытие |
| **Положение** | Как показывать ответ, на каком мониторе, в каком месте экрана, отступы. Кнопка «Предпросмотр» показывает результат сразу |
| **Общие** | Размер снимка, текст к снимку, формулы, постоянные инструкции |

Пара возможностей, о которых легко не догадаться:

- **Пометки по всему экрану** (вкладка «Положение» → «Как показывать ответ»).
  Вместо панели с текстом нейросеть обводит нужные места на экране рамками с
  номерами и подписывает их. Удобно, когда надо показать, *куда нажать* или *где
  ошибка*.
- **Формулы** (вкладка «Общие»). В режиме «LaTeX» формулы рисуются красиво, как в
  учебнике. В режиме «Простой текст» — обычными символами вроде x², √x.
- **Постоянные инструкции** (вкладка «Общие» → «Открыть постоянные инструкции»).
  Текст из этого файла получают все нейросети во всех чатах. Например: *«Отвечай
  по-русски»*.

## Если что-то не работает

**При запуске `install` пишет, что Python не найден.**
Python не установлен или при установке не стояла галочка «Add python.exe to PATH».
Запусти установщик Python ещё раз, выбери *Modify* / *Repair* и включи эту галочку
(или удали Python и поставь заново).

**Двойной щелчок по `start_manager` ничего не открывает.**
Скорее всего, не запускалась установка — сначала запусти `install`. На Linux и macOS
запусти файл из терминала (`bash linux/start_manager.sh`) — так будет видна ошибка.

**Нажимаю горячие клавиши — ничего не происходит.**
- Проверь, что оверлей запущен: в «Управлении» вверху должно быть «● работает».
- Возможно, это сочетание занято другой программой — назначь другое в настройках.
- Linux: нужен сеанс Xorg (см. [Linux](#linux)). macOS: нужны разрешения
  (см. [macOS](#macos)).

**Пишет «Не выполнен вход» или «Нет ключа».**
«Управление» → ⚙ Настройки → Нейросети → выбери нужную нейросеть → войди заново или
вставь ключ → «Проверить».

**Пишет «Claude Code не найден».**
⚙ Настройки → Нейросети → Claude → «Установить Claude Code». Если он уже установлен,
укажи путь к нему в поле «Путь к Claude Code» (на Windows обычно
`C:\Users\<имя>\.local\bin\claude.exe`).

**Ошибка при установке Codex.**
Установи [Node.js](https://nodejs.org) (кнопка LTS), перезапусти «Управление» и
снова нажми «Установить Codex».

**Ошибка соединения у ChatGPT, Gemini, Grok или OpenRouter.**
Из России они работают только через VPN — включи его. Без VPN можно пользоваться
GigaChat.

**Нейросеть отвечает, что не видит картинку.**
Выбранная модель не умеет смотреть изображения. Нажми «Список моделей» и выбери
другую.

**«Чат сейчас занят».**
В этом чате уже идёт ответ — из «Управления» или из оверлея. Дождись его или нажми
`Ctrl+Alt+X`, чтобы остановить.

**Ответ приходит долго.**
Первый запрос в чате всегда медленнее. Ускорить можно, выбрав модель попроще
(например, `sonnet` у Claude) или понизив уровень усилий.

**Панель закрывает что-то нужное.**
`Ctrl+Alt+H` — скрыть, `Ctrl+Alt+M` — перетащить в другое место. Постоянное место
задаётся во вкладке «Положение».

## Где хранятся данные, обновление и удаление

Всё лежит **в папке программы** — в системные папки ничего не пишется:

| Что | Где |
|---|---|
| Настройки | `config.json` |
| Чаты | `data/chats/` |
| Ключи и токены | `data/secrets.json` (на Windows — в зашифрованном виде, расшифровать можно только под твоей учётной записью) |
| Прикреплённые файлы и постоянные инструкции | `workspace/` |
| Установленные модули (Linux, macOS) | `.venv/` |

Эти файлы появляются сами при первом запуске. Ключи никуда не отправляются, кроме
сайта самой нейросети.

**Как обновить программу.** Закрой оверлей и «Управление». Скачай новый ZIP и
распакуй его. Перенеси из старой папки в новую `config.json`, папки `data` и
`workspace` — так сохранятся настройки и чаты. Запусти `install` ещё раз.

**Как удалить.** Закрой оверлей и «Управление» и удали папку программы целиком.
Claude Code и Codex, если их ставила программа, удаляются отдельно.

## Безопасность

- **Claude** может только **читать** файлы в папке `workspace`. Запускать команды,
  изменять файлы и ходить в интернет ему запрещено.
- **ChatGPT (Codex)** работает в режиме **«только чтение»**.
- **Нейросети по ключу** вообще не имеют доступа к компьютеру — им отправляется
  только текст и снимок экрана.
- Снимок делается **только когда ты нажимаешь клавиши**. В фоне программа экран не
  записывает.
