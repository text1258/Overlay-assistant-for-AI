# Claude поверх экрана

Экранный помощник, который работает по **подписке Claude (Pro/Max)**, без API-ключа.
Запросы идут через официальный Claude Code: он входит в твой аккаунт так же, как
claude.ai, и расходует лимиты подписки.

Приложение состоит из **двух отдельных программ**:

| Программа | Запуск | Что делает |
|---|---|---|
| **Управление** | `start_manager_*` | Чаты и выбор, с каким работает оверлей; загрузка контекста (переписка, файлы); настройки; запуск и остановка оверлея |
| **Оверлей** | `start_overlay_*` | Работает в фоне без окон: горячие клавиши → скриншот → ответ в полупрозрачной панели поверх экрана. Панель пропускает клики мыши |

Программы работают с общими данными: оверлей отвечает в чате, выбранном в
«Управлении», а его ответы сразу появляются в переписке этого чата. Оверлей можно
запускать и без открытого «Управления».

## Что где лежит

```
start_manager_*      — запуск «Управления» (чаты, контекст, настройки)
start_overlay_*      — запуск оверлея (горячие клавиши + панель)
install_*            — установка зависимостей
src/                 — код программы
config.json, data/, workspace/ — твои настройки, чаты и файлы (создаются сами)
```

Окончание имени — для какой системы: `_windows.bat`, `_linux.sh`, `_macos.command`.

## Установка

Нужен **Python 3.10+**. Claude Code ставить заранее не обязательно: после первого
запуска «Управления» откроется **⚙ Настройки → Нейросети → Claude**, где есть кнопки
«Установить Claude Code», «Войти через браузер» и «Войти по ссылке». При входе по
ссылке браузер сам не открывается: ссылку можно скопировать и открыть где угодно.

### Windows
1. Поставь Python с python.org, отметив «Add Python to PATH».
2. Запусти `install_windows.bat`.
3. Запускай `start_manager_windows.bat` и `start_overlay_windows.bat`.

### Linux
1. Нужны `python3`, `python3-venv` и `python3-tk`
   (Ubuntu/Debian: `sudo apt install python3 python3-venv python3-tk`).
2. `./install_linux.sh` — создаст `.venv` и поставит зависимости.
3. Запускай `./start_manager_linux.sh` и `./start_overlay_linux.sh`.

Горячие клавиши и скриншоты работают в сеансе **Xorg (X11)**. В Wayland выбери на
экране входа «Ubuntu on Xorg» или аналог. Панель пропускает клики и не заходит на
панели рабочего стола.

### macOS
1. Поставь Python с python.org (в нём есть Tk) или `brew install python python-tk`.
2. Двойной щелчок по `install_macos.command`. Если macOS не даёт открыть — правый
   щелчок → «Открыть».
3. Запускай `start_manager_macos.command` и `start_overlay_macos.command`.
4. Дай разрешения Терминалу (или Python) в «Системные настройки → Конфиденциальность
   и безопасность»: **Универсальный доступ** — для горячих клавиш, **Запись экрана** —
   для скриншотов.

Экраны Retina учитываются автоматически; панель не заходит под меню-бар и Док.

## Нейросети

Каждый чат работает со своей нейросетью: выбор вверху окна «Управление».
Подключение — **⚙ Настройки → Нейросети**: сверху выбираешь нейросеть, ниже —
её способ доступа и собственные настройки (модель, усилия, ключ, вход), кнопка
«Проверить» отправляет пробный запрос. Галочка «по умолчанию для новых чатов»
задаёт нейросеть для новых чатов.

| Нейросеть | Способы доступа |
|---|---|
| **Claude** | подписка (вход в аккаунт) · токен подписки (`claude setup-token`) · API-ключ Anthropic (оплата за токены) |
| **ChatGPT** | подписка ChatGPT, в т. ч. бесплатная (через Codex CLI) · API-ключ OpenAI (оплата за токены) |
| **Gemini** | API-ключ Google AI Studio — есть бесплатный тариф |
| **Grok** | API-ключ xAI (оплата за токены) |
| **OpenRouter** | API-ключ — много моделей, есть бесплатные (`:free`, 50 запросов в день) |
| **Ollama** | локально, без ключа и интернета (нужна видеокарта) |
| **GigaChat** | ключ авторизации Сбера — есть бесплатный режим, работает без VPN |

- Для скриншотов нужна модель, которая **видит картинки**: выбирай её в «Списке
  моделей» (для OpenRouter список показывает только такие).
- Ключи и токены хранятся только на этом компьютере (`data/secrets.json`, в Windows —
  в зашифрованном виде для твоей учётной записи).
- Если в чате сменить нейросеть, прошлая переписка передаётся новой как контекст.
- ChatGPT, Gemini, Grok и OpenRouter из России работают только через VPN. GigaChat
  может потребовать сертификат НУЦ Минцифры («Russian Trusted Root CA» с Госуслуг) —
  его можно установить в систему или указать файлом в настройках.
- Grok по подписке SuperGrok (через Grok Build) пока не поддерживается.

## Как пользоваться

1. **В «Управлении»** создай чат («+ Новый чат») или выбери существующий. Оверлей
   работает с тем чатом, который выбран в списке.
2. **Загрузи контекст**: напиши, что будешь присылать и как отвечать, прикрепи файлы
   (📎: PDF, картинки, txt/md/код, .docx). В поле **«Что делать со скриншотами»**
   можно задать инструкцию, которая уходит с каждым скриншотом в этом чате.
3. **Запусти оверлей**: кнопкой «▶ Запустить» вверху «Управления» или через
   `start_overlay_*`. «Управление» после этого можно закрыть.
4. Жми горячие клавиши:

| Клавиши | Что делает |
|---|---|
| `Ctrl+Alt+S` | скриншот всего экрана → Claude |
| `Ctrl+Alt+A` | выделить область мышью → Claude (Esc — отмена) |
| `Ctrl+Alt+H` | скрыть / показать панель |
| `Ctrl+Alt+PgUp` / `PgDn` | прокрутить длинный ответ |
| `Ctrl+Alt+M` | режим перемещения: перетащи панель мышью, повторное нажатие закрепит |
| `Ctrl+Alt+C` | открыть «Управление» |
| `Ctrl+Alt+X` | остановить ответ |
| `Ctrl+Alt+Q` | закрыть оверлей |

Клавиши работают в любой раскладке. Поменять их можно в **⚙ Настройки → Горячие
клавиши**: «Изменить» → нажать новое сочетание. Кнопка ✕ отключает сочетание.
Пока открыто окно настроек, клавиши оверлея на паузе.

У каждого чата свой диалог с Claude: договорённости и файлы из одного чата не
смешиваются с другим. После перезапуска чаты продолжаются с того же места.

## Настройки (⚙ в «Управлении»)

- **Нейросети** — выбор нейросети, способ доступа, вход / ключи, модель, усилия
  (см. выше). Для Claude здесь же установка Claude Code, вход через браузер или по
  ссылке (браузер сам не открывается — ссылку можно скопировать).
- **Горячие клавиши** — назначить, отключить, вернуть по умолчанию.
- **Вид панели** — тема (тёмная, светлая, как в системе), размеры, шрифт,
  прозрачность, автоскрытие.
- **Положение** — как показывать ответ (текстом в панели или пометками по всему
  экрану), монитор, место на экране (9 точек), отступы, «не заходить на панель задач».
- **Общие** — размер скриншота, текст к скриншоту, формулы (LaTeX или простой
  текст), постоянные инструкции `workspace/CLAUDE.md` — их получают все нейросети.

Изменения вида и положения сразу видны в предпросмотре; запущенный оверлей
подхватывает настройки сам. Всё хранится в `config.json`, чаты — в `data/chats/`.

## Безопасность

Claude здесь может **только читать файлы** в папке `workspace`. Запуск команд,
изменение файлов и интернет отключены (`--tools Read`). ChatGPT (Codex) запускается в
режиме «только чтение» (`-s read-only`). Нейросети по API доступа к компьютеру не
имеют вовсе — им отправляется только текст и скриншот.

## Если что-то не так

- «Не выполнен вход» или «нет ключа»: «Управление» → ⚙ Настройки → Нейросети →
  нужная нейросеть → вход или ключ.
- «Не найден Claude Code»: ⚙ Настройки → Нейросети → Claude → «Установить», или укажи
  путь там же. Обычно это `C:\Users\<имя>\.local\bin\claude.exe`.
- Горячая клавиша «занята другой программой»: назначь другую в ⚙ Настройки.
- «Чат сейчас занят»: в этом чате уже отвечает Claude (из «Управления» или оверлея),
  дождись ответа.
- Ответ долгий: первый запрос в чате всегда медленнее. Для скорости выбери `sonnet`.
- Лимиты общие с claude.ai: каждый скриншот расходует сообщение из подписки.

## Обновление со старой версии

Единственный диалог из первой версии (`state.json`) при первом запуске
автоматически переносится в чат «Чат 1».
